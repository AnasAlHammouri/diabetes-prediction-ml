# 🩺 Diabetes Prediction & Classification Project

An end-to-end Machine Learning project to predict diabetes risk using the **Pima Indians Diabetes Dataset**.

---

## 📌 Overview
This project builds, trains, and evaluates multiple supervised machine learning classification models to determine whether a patient is diabetic based on physiological measurements.
